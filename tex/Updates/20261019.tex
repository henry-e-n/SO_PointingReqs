It looks like the key to getting the toast sim to apply the custom pointing was to add the following arguments to the toast sim command line:

\begin{verbatim}
    --det_pointing_radec_sim.enable \
    --det_pointing_azel_sim.enable \
    --scan_map_pixels.enable \
    --scan_map_pixels.nside 8192 \
\end{verbatim}
